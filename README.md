# scTHREAD

scTHREAD is a single-cell long-read transcript database for human and mouse
(Oxford Nanopore and PacBio). The live database is freely accessible at
https://scthread.ai4sc.ac.cn/ (no login required).

## Archive contents

`release/` — the frozen release reported in the manuscript (453 run records,
34 datasets, 923,389 cells). `release_manifest.tsv` lists every source
accession; raw sequencing data should be retrieved from the original archives
using those accessions.

Figures, supplementary tables and full metadata are in the manuscript and at
the database portal.
